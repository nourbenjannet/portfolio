## 🚀 Comment déployer ce portfolio sur GitHub Pages

Ce dossier contient un site web complet (`index.html`, `styles.css`, `script.js`). Pour le publier gratuitement sur GitHub :

### Étape 1 : Initialiser le dépôt Git et commiter les fichiers
Ouvrez votre terminal dans ce dossier et exécutez :
```bash
git init
git add .
git commit -m "Initial commit - Portfolio Nour Ben Jannet"
```

### Étape 2 : Lier votre dépôt GitHub distant
Créez un nouveau repository public sur votre compte GitHub (ex: `portfolio-nour`), puis liez-le :
```bash
git branch -M main
git remote add origin https://github.com/VOTRE_NOM_UTILISATEUR/portfolio-nour.git
git push -u origin main
```

### Étape 3 : Activer GitHub Pages
1. Rendez-vous sur votre dépôt GitHub.
2. Allez dans **Settings** > **Pages** (dans le menu de gauche).
3. Sous **Branch**, sélectionnez `main` et le dossier `/(root)`.
4. Cliquez sur **Save**.
5. Votre site sera automatiquement en ligne à l'adresse :  
   `https://VOTRE_NOM_UTILISATEUR.github.io/portfolio-nour/`
